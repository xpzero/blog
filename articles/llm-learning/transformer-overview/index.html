前两篇留了一个断层：Token 把文本切成了数字 ID，Embedding 说模型内部处理的是向量——那么从"一串 ID 进去"到"下一个词出来"，中间到底经过了什么？

这一站先看地图再逛街：本篇只讲整体结构和数据流向，注意力、位置编码两个关键部件留给后面两篇拆开细看。不涉及公式，涉及的每个部件都给出它"消费什么、产出什么"。

先说清楚模型在做的事​

抛开所有神秘感，聊天模型的核心任务只有一个：

给定一段已有的 token 序列，算出下一个 token 是词表中每个候选的概率。

输入 ["今天", "天气", "很"]，输出是一张概率表：好: 21%，热: 13%，冷: 9%，…（词表有多大，这张表就有多长——上一篇查过，o200k_base 约 20 万项）。生成一整段话，就是把这个"预测下一个词"重复几百次，每次把新词接到末尾再来一轮。这个循环怎么跑、为什么首字慢，是第 7 篇的主题；本篇聚焦单次预测的内部。

一次前向传播的完整路线​

图中数据从下往上流，一共五站（图内标签为英文术语，下文逐个对应）：

① Token IDs：入口​

上一篇的产物。"Hello, how are you?" 进来时已经是 [13225, 11, 1495, ...] 这样的整数序列，模型看不到原始文字。

② Embedding Lookup：查表换向量​

拿每个 ID 去一张巨大的表里查出对应向量——就像按页码翻字典，13225 号翻到第 13225 条，取出预先存好的几千个数字。从这里开始，整个模型内部流动的都是向量，直到最后一站才回到"词"的世界。

旁边挂着的 + Position Info（位置信息） 是个容易被忽略的细节：后面的注意力机制天生不感知顺序，"我打你"和"你打我"会被看成同一堆词。所以必须在这里把"每个 token 排第几"注入向量。怎么注入有好几种方案，值得单独一篇（第 5 篇）。

③ Transformer Layer × N：反复加工​

模型的主体，同一种结构堆几十层（图中画了 3 层示意，真实模型的 N 在几十到上百）。每层内部两个部件接力：

  • Attention（注意力）：让每个位置的向量"看一眼"前面所有位置，把相关位置的信息按权重吸收进来。这是 token 之间唯一交换信息的通道，也是第 4 篇的主角。
  • Feed Forward（前馈网络）：对每个位置的向量独立做一次变换，不看别的位置。常被解读为"存储知识、加工特征"的部分，参数量占大头。

一层的产出还是同样形状的一组向量，直接作为下一层的输入。层数多的直观意义：底层处理表面模式（搭配、语法），越往上聚合的语义越抽象——这是研究中的普遍观察，不是严格定义。

④ LM Head：从向量回到词表​

把最后一层输出的向量投影回词表空间：产出约 20 万个分数，每个分数对应词表里的一个 token，分数越高表示模型越倾向选它。这组原始分数叫 logits——它们只是任意大小的实数（可能是 6.2、-3.1 这种），加起来不等于 1，还不能当概率用。

⑤ Probabilities：概率表​

最后一步把 logits 换算成概率，用的函数叫 softmax。不用管公式，它做的事很直白：把一组任意分数变成一组 0~1 之间、总和为 1 的比例，并且分数越高占比越大、高分之间的差距会被放大。感受一下：

logits:   好 → 6.2    热 → 5.7    冷 → 5.3    …（其余 20 万项分数更低）
softmax:  好 → 21%    热 → 13%    冷 → 9%     …（全部加起来 = 100%）

这就是图顶部的条形图，the 最高。到这里模型的工作就结束了。 挑哪个词（一定选最高？还是抽签？）是采样策略的事，temperature、top_p 都作用在这一步之后，留给第 6 篇。

值得记住的三个结构事实​

  • 只有注意力让 token 互通。 Embedding 查表、前馈网络、LM Head 都是每个位置各算各的。所以"模型怎么理解上下文"这个问题，答案几乎全在注意力里。
  • 每一站的输出形状不变。 进来 n 个 token，每层出来还是 n 组向量。模型不"压缩"也不"总结"你的输入，全部 token 一路带到最后——这也是上下文长度直接推高显存和计算量的原因（第 8 篇）。
  • 一次预测，全网络参与。 哪怕只生成一个标点，也要把几十层全部走一遍。"模型多少 B 参数"里的参数，主要就分布在 ③ 的注意力和前馈网络里。

名词对照​

以后查资料（大多是英文的）时会撞上这些说法，先对上号：这类"只往后预测"的结构叫 decoder-only Transformer（GPT 系、Llama 系、Qwen 系都是）；原始论文 Attention Is All You Need 里还有 encoder 部分，现代聊天模型基本不用了。图里的 Transformer Layer 在论文里叫 Transformer block，Attention 完整名称是 self-attention（自注意力）。
