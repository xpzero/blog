yarn常用命令记录

2022年1月9日 · 阅读需 1 分钟

查询帮助列表​

yarn help

初始化项目​

yarn init

安装所有依赖​

yarn
# 或者
yarn install

添加依赖​

# 安装指定依赖包
yarn add [packageName]
# 安装指定版本的依赖包
yarn add [packageName]@[version]
# 安装指定标签的依赖包
yarn add [packageName]@[tag]

# 安装包到开发依赖
yarn add [packageName] --dev

# 参数简写
--dev # 简写为 -D，添加到开发依赖（如果没有指定参数，默认安装到生产依赖）

升级依赖​

# 升级指定依赖包
yarn up [packageName]
# 升级指定版本的依赖包
yarn up [packageName]@[version]
# 升级指定标签的依赖包
yarn up [packageName]@[tag]

移除依赖​

yarn remove [packageName]

运行package.json中的脚本命令​

yarn run <scriptName>
# yarn run test
# yarn test

更新yarn版本​

# 更新yarn到最新版本
yarn set version latest
yarn set version from sources

参考

https://yarnpkg.com/getting-started/usage
