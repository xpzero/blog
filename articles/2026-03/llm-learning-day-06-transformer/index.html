Day 6 - Transformer 架构：Attention Is All You Need

2026年7月30日 · 阅读需 5 分钟

发布时间：2026-03-25

今日学习目标​

  • 理解 Transformer 架构的核心设计思想
  • 掌握 Self-Attention 机制的工作原理
  • 了解 Multi-Head Attention 的作用
  • 理解 Position Encoding 的必要性
  • 动手实践：用 PyTorch 实现简化版 Transformer

为什么需要 Transformer？​

在 Transformer 出现之前，RNN 和 LSTM 是处理序列数据的主流方法。但它们有两个致命弱点：

  1. 并行计算困难：必须按顺序处理，无法充分利用 GPU 并行能力
  2. 长距离依赖问题：序列越长，早期信息越容易"遗忘"

2017 年，Google 的论文《Attention Is All You Need》提出了 Transformer，彻底改变了 NLP 领域。

Transformer 架构概览​

Transformer 由两部分组成：

Encoder（编码器）：理解输入
    ↓
Decoder（解码器）：生成输出

核心组件​

组件作用
Self-Attention计算序列中每个位置与其他位置的关系
Multi-Head Attention多组注意力并行计算，捕捉不同维度的关系
Feed Forward对每个位置独立进行非线性变换
Layer Norm稳定训练，加速收敛
Position Encoding注入位置信息（模型本身没有位置概念）

Self-Attention：核心机制​

直观理解​

想象你在读一句话："猫坐在垫子上，因为它很累。"

"它"指代什么？Self-Attention 会计算"它"与"猫"、"垫子"的相关性，发现"它"和"猫"关系最密切。

数学原理​

Self-Attention 通过三个矩阵计算：

  • Q (Query)：查询向量，"我要找什么信息"
  • K (Key)：键向量，"我有什么信息"
  • V (Value)：值向量，"信息的具体内容"

计算公式：

Attention(Q, K, V) = softmax(QK^T / √d_k) · V

为什么除以 √d_k？​

防止点积结果过大，导致 softmax 梯度消失。

Multi-Head Attention：多角度看问题​

单一注意力可能只能捕捉一种关系。Multi-Head 使用多组 Q、K、V 矩阵，从不同角度计算注意力：

Head 1: 关注语法关系
Head 2: 关注语义关系
Head 3: 关注指代关系
...

最后将所有头的输出拼接起来，再经过一个线性变换。

Position Encoding：告诉模型"在哪里"​

Transformer 不像 RNN 有天然的顺序概念，需要显式注入位置信息。

原始方法：正弦/余弦函数​

PE(pos, 2i) = sin(pos / 10000^(2i/d_model))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))

优点：

  • 可以处理任意长度的序列
  • 相对位置可以通过线性变换得到

现代方法：可学习的位置编码​

现在很多模型（如 GPT、BERT）直接使用可学习的参数作为位置编码。

动手实践：简化版 Transformer​

import torch
import torch.nn as nn
import math

class MultiHeadAttention(nn.Module):
    def __init__(self, d_model=512, num_heads=8):
        super().__init__()
        self.d_model = d_model
        self.num_heads = num_heads
        self.d_k = d_model // num_heads
        
        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)
        self.W_o = nn.Linear(d_model, d_model)
    
    def scaled_dot_product_attention(self, Q, K, V, mask=None):
        scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(self.d_k)
        if mask is not None:
            scores = scores.masked_fill(mask == 0, -1e9)
        attn_weights = torch.softmax(scores, dim=-1)
        return torch.matmul(attn_weights, V)
    
    def forward(self, query, key, value, mask=None):
        batch_size = query.size(0)
        
        # 线性变换并分头
        Q = self.W_q(query).view(batch_size, -1, self.num_heads, self.d_k).transpose(1, 2)
        K = self.W_k(key).view(batch_size, -1, self.num_heads, self.d_k).transpose(1, 2)
        V = self.W_v(value).view(batch_size, -1, self.num_heads, self.d_k).transpose(1, 2)
        
        # 计算注意力
        attn_output = self.scaled_dot_product_attention(Q, K, V, mask)
        
        # 拼接多头并线性变换
        attn_output = attn_output.transpose(1, 2).contiguous().view(batch_size, -1, self.d_model)
        return self.W_o(attn_output)

# 测试
mha = MultiHeadAttention(d_model=512, num_heads=8)
x = torch.randn(2, 10, 512)  # batch=2, seq_len=10, d_model=512
output = mha(x, x, x)
print(f"Input shape: {x.shape}")
print(f"Output shape: {output.shape}")

检查点问题​

  1. Self-Attention 和 Cross-Attention 有什么区别？

    Details

    点击查看答案 Self-Attention 的 Q、K、V 来自同一输入；Cross-Attention 的 Q 来自 Decoder，K、V 来自 Encoder。

  2. 为什么 Transformer 比 RNN 快？

    Details

    点击查看答案 Transformer 可以并行计算所有位置的注意力，而 RNN 必须顺序处理。

  3. Multi-Head Attention 中"头"的数量有什么影响？

    Details

    点击查看答案 头越多，模型可以从越多角度捕捉关系，但计算量也越大。通常 8-16 个头是常见选择。

今日总结​

Transformer 的核心创新：

  1. Self-Attention：让模型直接建模任意两个位置的关系
  2. 并行计算：摆脱 RNN 的顺序限制，充分利用 GPU
  3. Multi-Head：多角度捕捉序列中的复杂关系

理解 Transformer 是理解现代大语言模型的基础。明天我们将深入探讨训练过程。
