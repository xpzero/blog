Day 8 - 注意力机制进阶：从 Self-Attention 到 Multi-Head

回顾：Self-Attention 的核心思想​

在 Day 6 中，我们了解了 Transformer 的整体架构。今天深入其核心——Attention 机制。

Self-Attention 的本质：每个位置都能"看到"其他所有位置，并根据相关性加权聚合信息。

直观类比​

想象你在读一句话："猫坐在垫子上，因为它很累。"

读到"它"时，你的大脑会自动关联到"猫"而不是"垫子"。Self-Attention 就是让这个关联过程可计算、可学习。

Self-Attention 的数学细节​

输入表示​

假设输入序列长度为 n，每个词的 embedding 维度为 d_model：

X = [x₁, x₂, ..., xₙ]  (shape: n × d_model)

生成 Q、K、V​

通过三个可学习的权重矩阵：

Q = X · W_Q    (Query: 我要找什么)
K = X · W_K    (Key: 我有什么)
V = X · W_V    (Value: 信息内容)

W_Q, W_K, W_V 的 shape: d_model × d_k

Attention 计算公式​

Attention(Q, K, V) = softmax(QK^T / √d_k) · V

分步拆解：

  1. 计算相似度：QK^T (n × n 的相似度矩阵)
  2. 缩放：除以 √d_k，防止梯度消失
  3. 归一化：softmax 得到注意力权重
  4. 加权求和：与 V 相乘得到输出

为什么除以 √d_k？​

当 d_k 较大时，点积的数值会很大，导致 softmax 的梯度极小。

举例：

  • d_k = 64 时，√d_k = 8
  • 如果不缩放，点积可能达到 100+，softmax 接近 one-hot
  • 缩放后，数值分布更合理，梯度更稳定

Multi-Head Attention：多角度看问题​

核心思想​

单一注意力可能只能捕捉一种关系。Multi-Head 使用多组 Q、K、V，从不同角度计算注意力：

Head 1: 关注语法关系（主谓宾）
Head 2: 关注语义关系（同义词）
Head 3: 关注指代关系（代词指代）
...

数学实现​

# h 个头，每个头的维度 d_k = d_model / h

# 分头计算
head_1 = Attention(X·W_Q1, X·W_K1, X·W_V1)
head_2 = Attention(X·W_Q2, X·W_K2, X·W_V2)
...
head_h = Attention(X·W_Qh, X·W_Kh, X·W_Vh)

# 拼接并线性变换
MultiHead = Concat(head_1, ..., head_h) · W_O

代码实现​

import torch
import torch.nn as nn
import math

class MultiHeadAttention(nn.Module):
    def __init__(self, d_model=512, num_heads=8):
        super().__init__()
        self.d_model = d_model
        self.num_heads = num_heads
        self.d_k = d_model // num_heads
        
        # 线性变换层
        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)
        self.W_o = nn.Linear(d_model, d_model)
    
    def scaled_dot_product_attention(self, Q, K, V, mask=None):
        scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(self.d_k)
        
        if mask is not None:
            scores = scores.masked_fill(mask == 0, -1e9)
        
        attn_weights = torch.softmax(scores, dim=-1)
        return torch.matmul(attn_weights, V), attn_weights
    
    def forward(self, query, key, value, mask=None):
        batch_size = query.size(0)
        
        # 1. 线性变换
        Q = self.W_q(query)
        K = self.W_k(key)
        V = self.W_v(value)
        
        # 2. 分头 (batch, seq, heads, d_k) -> (batch, heads, seq, d_k)
        Q = Q.view(batch_size, -1, self.num_heads, self.d_k).transpose(1, 2)
        K = K.view(batch_size, -1, self.num_heads, self.d_k).transpose(1, 2)
        V = V.view(batch_size, -1, self.num_heads, self.d_k).transpose(1, 2)
        
        # 3. 计算注意力
        attn_output, attn_weights = self.scaled_dot_product_attention(Q, K, V, mask)
        
        # 4. 拼接多头
        attn_output = attn_output.transpose(1, 2).contiguous()
        attn_output = attn_output.view(batch_size, -1, self.d_model)
        
        # 5. 最终线性变换
        return self.W_o(attn_output), attn_weights

# 测试
mha = MultiHeadAttention(d_model=512, num_heads=8)
x = torch.randn(2, 10, 512)  # batch=2, seq_len=10
output, weights = mha(x, x, x)
print(f"Output shape: {output.shape}")  # [2, 10, 512]
print(f"Attention weights shape: {weights.shape}")  # [2, 8, 10, 10]

Position Encoding：注入位置信息​

为什么需要位置编码？​

Self-Attention 是位置无关的：无论词出现在哪里，计算方式都一样。

但语言是有顺序的："猫追老鼠" ≠ "老鼠追猫"

原始方法：正弦/余弦位置编码​

import numpy as np

def get_positional_encoding(seq_len, d_model):
    """
    生成正弦位置编码
    """
    position = np.arange(seq_len)[:, np.newaxis]  # [seq_len, 1]
    div_term = np.exp(np.arange(0, d_model, 2) * 
                      -(np.log(10000.0) / d_model))
    
    pe = np.zeros((seq_len, d_model))
    pe[:, 0::2] = np.sin(position * div_term)  # 偶数维度
    pe[:, 1::2] = np.cos(position * div_term)  # 奇数维度
    
    return pe

# 可视化
import matplotlib.pyplot as plt

pe = get_positional_encoding(100, 512)
plt.figure(figsize=(12, 6))
plt.imshow(pe, cmap='viridis', aspect='auto')
plt.colorbar()
plt.xlabel('Dimension')
plt.ylabel('Position')
plt.title('Positional Encoding Visualization')
plt.show()

特点​

  1. 唯一性：每个位置有唯一的编码
  2. 相对位置：PE(pos+k) 可以通过 PE(pos) 线性变换得到
  3. 有界性：值域在 [-1, 1] 之间

现代方法：可学习的位置编码​

class LearnablePositionalEncoding(nn.Module):
    def __init__(self, seq_len=512, d_model=512):
        super().__init__()
        self.pe = nn.Parameter(torch.randn(seq_len, d_model))
    
    def forward(self, x):
        # x: [batch, seq_len, d_model]
        return x + self.pe[:x.size(1)]

BERT、GPT 等现代模型使用可学习的位置编码。

Attention 的变体​

1. Cross-Attention（交叉注意力）​

场景：Encoder-Decoder 架构中，Decoder 关注 Encoder 的输出

Q 来自 Decoder（当前要生成的位置）
K, V 来自 Encoder（源语言的信息）

应用：机器翻译、摘要生成

2. Masked Self-Attention（掩码自注意力）​

场景：Decoder 中，防止看到未来的词

def create_look_ahead_mask(seq_len):
    """创建上三角掩码，防止看到未来信息"""
    mask = torch.triu(torch.ones(seq_len, seq_len), diagonal=1)
    return mask == 0  # 下三角为 True，上三角为 False

# 示例
mask = create_look_ahead_mask(5)
print(mask)
# tensor([[ True, False, False, False, False],
#         [ True,  True, False, False, False],
#         [ True,  True,  True, False, False],
#         [ True,  True,  True,  True, False],
#         [ True,  True,  True,  True,  True]])

应用：GPT 等自回归语言模型

3. Sparse Attention（稀疏注意力）​

问题：标准 Attention 的复杂度是 O(n²)，长序列时计算量巨大

解决方案：

  • 局部注意力：只关注附近的词
  • 全局注意力：某些位置可以关注所有位置
  • 随机注意力：随机选择一些位置关注

应用：Longformer、BigBird 等长文档模型

动手实践：可视化 Attention 权重​

import matplotlib.pyplot as plt
import seaborn as sns

def visualize_attention(attention_weights, tokens, title="Attention Weights"):
    """
    可视化 Attention 权重
    attention_weights: [num_heads, seq_len, seq_len]
    tokens: 词列表
    """
    num_heads = attention_weights.size(0)
    fig, axes = plt.subplots(2, num_heads//2, figsize=(16, 8))
    axes = axes.flatten()
    
    for i in range(num_heads):
        ax = axes[i]
        sns.heatmap(attention_weights[i].detach().numpy(),
                   xticklabels=tokens,
                   yticklabels=tokens,
                   cmap='YlOrRd',
                   ax=ax,
                   cbar=True)
        ax.set_title(f'Head {i+1}')
        ax.set_xlabel('Key Position')
        ax.set_ylabel('Query Position')
    
    plt.suptitle(title)
    plt.tight_layout()
    plt.show()

# 示例使用
tokens = ['[CLS]', '猫', '坐', '在', '垫子', '上', '，', '它', '很', '累', '[SEP]']
x = torch.randn(1, len(tokens), 512)

mha = MultiHeadAttention(d_model=512, num_heads=8)
output, attn_weights = mha(x, x, x)

# 可视化第一个样本的第一个头的注意力
visualize_attention(attn_weights[0], tokens, "Multi-Head Attention Visualization")

检查点问题​

  1. 为什么 Multi-Head Attention 比单头更好？

    Details

    点击查看答案 Multi-Head 允许模型从多个角度（语法、语义、指代等）捕捉关系，增强表达能力。每个头可以学习不同类型的注意力模式。

  2. Position Encoding 和 Position Embedding 有什么区别？

    Details

    点击查看答案 Position Encoding 是固定的（如正弦函数），Position Embedding 是可学习的参数。现代模型（BERT、GPT）多用可学习的 Embedding。

  3. Masked Attention 在 Decoder 中的作用是什么？

    Details

    点击查看答案 防止 Decoder 在生成当前词时"偷看"未来的词，保证自回归生成的正确性。

今日总结​

Attention 机制的核心要点：

  1. Self-Attention：通过 Q、K、V 计算位置间的相关性，实现全局信息聚合
  2. Multi-Head：多组注意力并行，捕捉不同类型的关系
  3. Position Encoding：注入位置信息，让模型感知顺序
  4. 变体：Cross-Attention（跨模态）、Masked Attention（自回归）、Sparse Attention（长序列）

Attention 是 Transformer 的灵魂，理解它是理解现代大模型的关键。
