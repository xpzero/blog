Day 6：Transformer 架构——Attention Is All You Need

2026年3月24日 · 阅读需 3 分钟

今天终于进入了第二阶段的核心：Transformer。2017 年那篇论文的标题现在回头看，简直像预言。

为什么需要 Transformer​

RNN 和 LSTM 最大的问题是慢。序列得一个一个处理，没法并行。而且长距离依赖容易丢——前面说的东西，后面根本记不住。

Transformer 的思路很暴力：干脆不要序列了，直接看全部。用 Attention 机制让每个词都能「看到」其他所有词，距离就不再是问题。

整体架构​

Transformer 是个 Encoder-Decoder 结构，但跟以前的 Seq2Seq 不太一样：

Input → [Encoder] × N → Context → [Decoder] × N → Output

Encoder 把输入变成一堆向量表示，Decoder 基于这些向量生成输出。两边都是堆叠的相同层，原论文堆了 6 层。

Self-Attention 机制​

这是 Transformer 的核心。简单说：每个词都要看看其他所有词，决定该关注谁。

计算过程：

  1. 每个词生成三个向量：Query、Key、Value
  2. Query 跟所有 Key 做内积，得到注意力分数
  3. Softmax 归一化，得到注意力权重
  4. 权重 × Value，加权求和就是输出

公式：

Attention(Q, K, V) = softmax(QK^T / √d_k) V

除以 √d_k 是为了防止点积太大，导致 softmax 梯度消失。

Multi-Head Attention​

一个 Attention 可能看不过来，那就搞多个「头」，每个头关注不同的方面。

原论文用了 8 个头，每个头的维度是 64（总共还是 512）。最后把 8 个头的输出拼起来，再做个线性变换。

MultiHead(Q, K, V) = Concat(head_1, ..., head_h) W^O
where head_i = Attention(QW_i^Q, KW_i^K, VW_i^V)

位置编码​

Attention 本身没有位置信息，「我爱你」和「你爱我」对它来说完全一样。得显式加入位置信息。

原论文用的是 Sinusoidal 编码：

PE(pos, 2i) = sin(pos / 10000^(2i/d_model))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))

这样设计的好处是可以外推到更长的序列。后来也有人用 Learned Positional Encoding，直接让模型自己学。

其他组件​

Feed-Forward Network 每个位置独立应用的全连接层：

FFN(x) = max(0, xW_1 + b_1)W_2 + b_2

就是 ReLU 激活的两层线性变换，中间维度 2048。

Layer Normalization 每个子层后面加 LayerNorm，训练更稳定。

残差连接 每个子层都是：LayerNorm(x + Sublayer(x))

Masking Decoder 的 Self-Attention 要 mask 掉后面的词，防止偷看答案。

为什么 Transformer 这么强​

并行化：不像 RNN 必须串行，Transformer 可以并行计算所有位置的 Attention。

长距离依赖：任意两个词的距离都是 O(1)，不再随序列长度增加。

可解释性：Attention 权重可以可视化，看模型到底在关注什么。

实际影响​

Transformer 出来后，NLP 领域彻底变了：

  • BERT（Encoder-only）→ 理解任务
  • GPT（Decoder-only）→ 生成任务
  • T5（Encoder-Decoder）→ 翻译/摘要

现在的 LLM 基本都是 Decoder-only 的 Transformer，堆了几十层，训练数据量爆炸。
