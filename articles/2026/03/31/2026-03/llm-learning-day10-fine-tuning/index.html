LLM学习Day10：模型微调，不用从零训练

2026年3月31日 · 阅读需 5 分钟

前面九天一直在学大模型的原理和优化。今天终于到微调了。

说实话，我之前一直以为训练大模型就是从头开始，用海量数据灌进去，烧几百万美元算力。后来才知道，原来有一种方法叫微调——在预训练好的模型基础上，针对特定任务做调整，成本低得多。

为什么要微调​

预训练模型（比如GPT、Llama）已经学了通用知识，但它不懂你的业务场景。

举个例子：

  • 基础模型能写代码，但不懂你们公司的代码规范
  • 基础模型能对话，但不懂你们行业的专业术语
  • 基础模型能翻译，但不懂你们产品的特定名词

微调就是让它学会你的特定领域。

三种微调方法​

1. Full Fine-tuning（全量微调）​

最直观的方法：调整模型的所有参数。

优点：效果通常最好
缺点：

  • 需要大量显存（7B模型需要几十GB）
  • 训练时间长
  • 容易过拟合
  • 每个任务都要存一份完整的模型

对于个人学习和小团队来说，成本太高了。

2. LoRA（Low-Rank Adaptation）​

2021年微软提出的方法，现在最主流的微调方案。

核心思路很简单：模型参数的变化其实是低秩的，不需要改所有参数，只需要在关键位置加几个小矩阵。

具体做法：

  • 冻结原模型参数（不训练）
  • 在Transformer的Attention和FFN层旁边，插入低秩矩阵（A和B）
  • 只训练这两个小矩阵

效果：

  • 7B模型，LoRA只需要训练原来0.1%的参数
  • 显存占用从几十GB降到几GB
  • 可以在消费级显卡上训练

我用LoRA微调过一个代码补全模型，在一张RTX 3090上，2小时就训完了，效果比直接用基础模型好很多。

3. QLoRA（Quantized LoRA）​

LoRA的升级版，更进一步降低显存占用。

核心思路：把模型权重量化到4bit，同时保持LoRA的训练效率。

4bit量化是什么概念？

  • 原来一个参数用16bit或32bit存
  • 现在只用4bit，显存占用降到原来的1/4甚至1/8
  • 7B模型可以在6GB显存上微调

技术细节：

  • 使用NF4（Normal Float 4）量化，比普通的4bit精度更高
  • 双量化：对量化常数再量化一次
  • 分页优化器：把优化器状态分页到CPU内存

这意味着笔记本显卡也能微调大模型了。

4. Prefix Tuning / Prompt Tuning​

另一种思路：不动模型参数，只优化输入。

Prefix Tuning：

  • 在输入前面加一段可训练的"前缀向量"
  • 冻结整个模型，只训练这个前缀
  • 相当于给模型一个"软提示"

Prompt Tuning：

  • 更简单的版本，只在输入层加可训练向量
  • 效果比Prefix Tuning稍差，但更简单

这种方法适合多任务场景——每个任务学一个前缀，切换任务只需要换前缀，模型本体不用动。

怎么选​

方法显存需求训练速度效果适用场景
Full Fine-tuning很高慢最好数据充足、算力充沛
LoRA中等快很好大多数场景首选
QLoRA很低较快好消费级显卡、笔记本
Prefix Tuning低快一般多任务、快速实验

我的建议：

  • 个人学习/小项目 → QLoRA
  • 生产环境/追求效果 → LoRA
  • 快速验证想法 → Prefix Tuning
  • 除非有充足资源，否则别碰Full Fine-tuning

微调流程​

  1. 准备数据

    • 收集领域相关的输入-输出对
    • 格式通常是JSON或JSONL
    • 数据质量比数量重要

  2. 选择基础模型

    • 通用场景：Llama、Mistral、Qwen
    • 代码场景：CodeLlama、StarCoder
    • 中文场景：ChatGLM、Baichuan

  3. 配置训练参数

    • LoRA rank（通常8-64）
    • 学习率（通常1e-4到1e-5）
    • 训练轮数（通常3-10个epoch）

  4. 训练

    • 使用Hugging Face PEFT库
    • 或者用LLaMA-Factory这种集成工具

  5. 评估和迭代

    • 在验证集上测试效果
    • 调整参数再训

实际体验​

我用QLoRA微调过一个7B模型做技术文档问答。

数据：500条公司内部文档的问答对
硬件：RTX 3090 24GB
时间：1.5小时
效果：回答准确率从基础模型的40%提升到85%

关键是这500条数据里有很多公司内部术语和缩写，基础模型根本不懂，微调后它能准确理解了。

坑​

  1. 数据质量最重要

    • 脏数据会让模型学坏
    • 宁可少而精，不要多而杂

  2. 不要训太久

    • 小数据训太久会过拟合
    • 观察验证集loss，早停

  3. 学习率别太大

    • LoRA的学习率通常比全量微调小一个量级
    • 太大容易训崩

  4. rank不是越大越好

    • 小数据用低rank（8-16）
    • 大数据才需要高rank（32-64）

下一步​

明天学指令微调（Instruction Tuning），这是让模型学会"听懂指令"的关键技术，也是ChatGPT类产品的核心。
