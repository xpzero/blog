Agent学习

这里用于记录 AI Agent 的学习和实践。Agent 不是“更聪明的聊天框”，而是让模型在明确权限、工具输入输出和人工确认下，完成多步任务的应用方式。

后续笔记会围绕工具设计、任务状态、评测、权限与安全边界展开。没有经过验证的方案会明确标注为草稿或待验证结论。

概念​

这一部分梳理 Agent 的核心组成、运行机制与安全边界，帮助建立理解具体实现时需要的整体心智模型。

  • Claude Code 工作原理：从语言模型到可执行 Agent

系列：从零手写 Agent​

不依赖任何 Agent 框架，只用 OpenAI SDK，从一次最简单的 API 调用开始，一步步做出能调用工具、能多轮对话、能流式输出、能读写文件和联网搜索、能管理多条会话的命令行 Agent。每篇从一个具体问题出发，代码对应公开仓库 xpzero/demo-agent 的一次提交。

篇标题解决的问题
一第一次用代码调用大模型怎么用代码而不是网页调用模型
二让模型用上它接触不到的数据内部系统数据、实时信息怎么给模型
三为什么它记不住上一句话多轮对话与双层循环
四流式输出，以及被切碎的工具调用逐字输出，以及 chunk 碎片如何归拢
五让 Agent 读写本地文件真实文件操作与路径安全边界
六接上联网搜索，同时接上风险获取实时信息，以及 prompt injection
七让多个话题互不干扰多会话隔离与磁盘持久化
八把它接上网页事件化改造、SSE 与前后端联通
九从 Chat Completions 切到 Responses APItyped events、Items 与工具调用协议迁移
十工具明明执行了，为什么页面上看不见？在网页中展示工具状态、参数和结果
十一给工具调用加上权限判断和用户审批allow、ask、deny 权限裁决与审批恢复
