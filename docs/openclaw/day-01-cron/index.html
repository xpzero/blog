Day 1：定时任务管理（Cron）

今日主题​

学习如何使用 OpenClaw 的 Cron 功能实现自动化任务调度。

知识讲解​

什么是 Cron？​

Cron 是 OpenClaw 的定时任务系统，用于在指定时间自动执行预设任务。

类比理解：

  • 就像手机的闹钟
  • 就像日历的提醒
  • 按照设定的时间自动触发

核心概念​

概念说明示例
Cron 表达式定义执行时间规则30 7 * * * 每天早上7:30
任务载荷任务执行时发送的消息学习提醒内容
投递目标消息发送到哪里飞书用户/群

Cron 表达式格式​

┌───────────── 分钟 (0-59)
│ ┌───────────── 小时 (0-23)
│ │ ┌───────────── 日期 (1-31)
│ │ │ ┌───────────── 月份 (1-12)
│ │ │ │ ┌───────────── 星期 (0-7, 0和7都是周日)
│ │ │ │ │
* * * * *

常用示例：

表达式含义
0 9 * * *每天早上9点
0 0 * * 0每周日午夜
*/5 * * * *每5分钟
0 9,18 * * 1-5工作日早9晚6

代码示例​

查看所有 Cron 任务​

openclaw cron list

输出示例：

ID                                   Name              Schedule
------------------------------------ ----------------- -------------------
d96e7272-5370-4202-8d51-2aeee58c431a llm-study-morning cron 30 7 * * *

创建新任务​

openclaw cron add \
  --name "daily-reminder" \
  --cron "0 9 * * *" \
  --message "早上好！记得完成今天的学习任务" \
  --to "ou_baa1a8b44a4b6252542b2b9795d53931" \
  --channel feishu

删除任务​

# 通过名称删除
openclaw cron rm daily-reminder

# 或通过 ID 删除
openclaw cron rm d96e7272-5370-4202-8d51-2aeee58c431a

修改任务​

openclaw cron edit d96e7272-5370-4202-8d51-2aeee58c431a \
  --message "新的提醒内容"

动手练习​

练习 1：创建测试任务​

创建一个每5分钟触发一次的测试任务：

openclaw cron add \
  --name "test-every-5min" \
  --cron "*/5 * * * *" \
  --message "测试消息：每5分钟一次" \
  --to "你的用户ID" \
  --channel feishu

观察： 是否每5分钟收到消息？

练习 2：修改现有任务​

修改 llm-study-morning 任务的提醒内容：

openclaw cron edit llm-study-morning \
  --message "🌅 新的一天开始了！今天的学习主题是：XXX"

练习 3：禁用和启用任务​

# 禁用任务
openclaw cron edit llm-study-morning --disable

# 启用任务
openclaw cron edit llm-study-morning --enable

实际应用场景​

场景 1：学习提醒​

需求： 每天早上推送学习内容

配置：

openclaw cron add \
  --name "daily-study" \
  --cron "30 7 * * *" \
  --message "📚 今日学习：Day X - 主题" \
  --to "用户ID" \
  --channel feishu

场景 2：定期报告​

需求： 每周日晚上生成周报

配置：

openclaw cron add \
  --name "weekly-report" \
  --cron "0 20 * * 0" \
  --message "生成本周学习报告" \
  --to "用户ID" \
  --channel feishu

场景 3：健康提醒​

需求： 每小时提醒喝水

配置：

openclaw cron add \
  --name "water-reminder" \
  --cron "0 * * * *" \
  --message "💧 该喝水啦！" \
  --to "用户ID" \
  --channel feishu
