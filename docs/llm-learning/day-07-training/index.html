Day 7：训练过程

知道模型架构后，自然会问：这些参数怎么学出来的？答案是训练。但这事比想象复杂。

预训练 vs 微调​

预训练​

在大规模无标注数据上训练，让模型学会语言通用规律。

数据：网页、书籍、代码、维基百科 目标：预测下一个 Token 成本：很高（GPT-3 花了 460 万美元）

小公司玩不起基座模型。

微调​

在特定任务的有标注数据上继续训练。

全量微调：更新所有参数，效果好但资源消耗大

参数高效微调（PEFT）：

  • LoRA：只训练低秩适配器，省 70% 显存
  • Prompt Tuning：只优化提示嵌入
  • Prefix Tuning：只训练前缀参数

我的选择：一般场景用 LoRA，效果损失不大，资源省很多。

损失函数​

交叉熵损失​

语言模型的标准损失函数。

import torch.nn as nn

criterion = nn.CrossEntropyLoss()
loss = criterion(logits.view(-1, vocab_size), targets.view(-1))

直观理解：模型预测的概率分布 vs 真实分布的差异。损失越小，预测越准。

困惑度（Perplexity）​

评估语言模型的指标。

Perplexity = exp(Loss)

意义：模型有多"困惑"，即平均有多少个等概率选择。

模型PPL
GPT-2~20
GPT-3~10
人类~5-8

优化器​

AdamW​

Transformer 的标准优化器。

from torch.optim import AdamW

optimizer = AdamW(
    model.parameters(),
    lr=5e-5,           # 学习率
    weight_decay=0.01  # 权重衰减，防过拟合
)

学习率调度​

Warmup：前 N 步线性增加学习率，防早期训练不稳定。

Cosine Decay：学习率按余弦曲线下降，比阶梯衰减平滑。

分布式训练​

数据并行​

每个 GPU 处理不同 batch，梯度聚合后更新。

问题：单卡显存要装下整个模型，大模型玩不起。

ZeRO​

把优化器状态、梯度、参数分片存储。

阶段说明显存节省
ZeRO-1分片优化器状态4x
ZeRO-2加分片梯度8x
ZeRO-3加分片参数与并行度线性相关

我的实践：7B 模型单卡 24G 训不动，用 ZeRO-2 + Offload 就能跑。

混合精度训练​

用 FP16/BF16 计算，FP32 存储，省显存又加速。

from torch.cuda.amp import autocast, GradScaler

scaler = GradScaler()

with autocast():
    outputs = model(batch)
    loss = criterion(outputs, targets)

scaler.scale(loss).backward()
scaler.step(optimizer)
scaler.update()

BF16 vs FP16：

  • BF16：范围大，精度低，更稳定
  • FP16：范围小，精度高，需要梯度缩放

A100 支持 BF16，推荐直接用。
