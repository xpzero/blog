Day 1：Token 是什么？

一句话理解​

Token 是大模型理解和生成文本的最小单位，就像乐高积木的一块块零件。

术语释义​

什么是 Token？​

Token（词元）是大语言模型处理文本时的基本单位。不同于我们理解的"字"或"词"，Token 是模型视角下的文本片段。

类比理解：

  • 人类阅读：以"字"和"词"为单位
  • 模型处理：以"Token"为单位
  • 就像拼图：人类看整体图案，模型看每一块拼图

中英文 Token 差异​

语言示例Token 数量说明
英文"Hello"1 个常见单词通常是 1 个 Token
英文"unhappiness"3 个["un", "happ", "iness"] 拆成子词
中文"你好"2 个每个汉字通常 1-2 个 Token
中文"机器学习"4 个可能比英文更"费"Token

为什么中文更"费"Token？

  • 英文有天然的分隔符（空格）
  • 中文需要更细粒度的切分
  • 结果：同样的意思，中文通常需要更多 Token

原理解释​

Tokenization 过程​

输入文本 → Tokenizer（分词器）→ Token 序列 → 模型处理

具体步骤：

  1. 文本输入："今天天气很好"
  2. 分词处理：["今天", "天气", "很", "好"] 或 ["今", "天", "天", "气", "很", "好"]
  3. 转为数字：每个 Token 对应一个数字 ID
  4. 模型计算：基于数字 ID 进行预测和生成

不同模型的 Tokenizer​

模型Tokenizer特点
GPT-4cl100k_base多语言优化
Claude自有方案对中文友好
Kimi自有方案中文场景优化

重要： 不同模型的 Token 计算结果可能不同！

实际应用​

场景 1：API 成本控制​

问题： 为什么同样的请求，有时费用不同？

答案： 按 Token 计费！

费用 = (输入 Token 数 + 输出 Token 数) × 单价

省钱技巧：

  • 精简提示词（去掉不必要的废话）
  • 英文比中文更省 Token（约 1:2 的比例）
  • 控制输出长度（设置 max_tokens）

场景 2：上下文窗口限制​

问题： 为什么长文档传不进去？

答案： 上下文窗口 = 模型能处理的 Token 上限

模型上下文窗口约等于
GPT-3.54K-16K3-12 页文档
GPT-4128K约 100 页文档
Claude 3200K约 150 页文档

应对策略：

  • 文档太长？分段处理
  • 对话太长？定期总结

场景 3：提示词优化​

对比：

❌ 低效（20 tokens）:
"请帮我分析一下下面这段文字的内容和含义"

✅ 高效（4 tokens）:
"分析："

动手实践​

任务 1：体验 Tokenizer​

  1. 访问 OpenAI Tokenizer
  2. 输入以下内容，观察 Token 数量：
文本Token 数观察
"Hello world"?英文短句
"你好世界"?中文短句
"Machine learning is fascinating and useful"?长英文
"机器学习非常有趣且实用"?长中文

思考： 同样的意思，中英文 Token 数差异大吗？

任务 2：计算 API 成本​

假设：

  • GPT-4 价格：$0.03/1K tokens（输入）
  • 你发送了 1000 字的报告（约 1500 tokens）
  • 模型回复了 500 字（约 750 tokens）

计算： 这次请求花费多少？

点击查看答案
总 Token = 1500 + 750 = 2250
费用 = 2250 / 1000 × $0.03 = $0.0675（约 0.5 元人民币）

任务 3：优化提示词​

优化以下提示词，减少 Token 数量：

"我想让你帮我写一个 Python 函数，这个函数的功能是计算两个数的和，
然后返回结果。请确保代码简洁明了，并且添加适当的注释。"

目标： 保持核心意思，Token 数减少 50%

检查点​

自测问题​

  1. 什么是 Token？

    Details

    答案 大模型处理文本的最小单位，可以是字、词或子词

  2. 为什么中文通常比英文消耗更多 Token？

    Details

    答案 中文没有空格分隔，需要更细粒度的切分

  3. Token 如何影响 API 成本？

    Details

    答案 按 Token 计费，输入+输出的总 Token 数决定费用

  4. 什么是上下文窗口？

    Details

    答案 模型能处理的最大 Token 数量，超过会被截断

今日总结​

核心概念：

  • ✅ Token 是模型的"文字积木"
  • ✅ 中英文 Token 效率不同
  • ✅ Token 影响成本和上下文限制

应用场景：

  • ✅ API 成本控制
  • ✅ 长文本处理策略
  • ✅ 提示词优化
