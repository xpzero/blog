Day 1：Token 与分词

大模型越来越火，Cursor、Claude Code、Copilot 这些工具身边人都在用。我再不学，感觉要被淘汰了。

Token、Prompt、RAG、Agent...这些词天天看到，完全不懂。从今天开始补。

大模型怎么认识文字？​

大模型不是人，它怎么"读"文字？

我们人类读书，一个字一个字地读。查了一圈，发现关键就两个字：Token。

Token 是什么？​

Token 是大模型处理文字的最小单位。

但不是我们想的那样"一个字"。英文通常按 subword（子词）来切：

输入Token 数怎么切
Hello1整个词
unhappiness3un + happ + iness
こんにちは3日语也按词切

中文没有空格，不好按词切，通常是字级别：

输入Token 数
你好2
今天天气很好6-8

怎么验证？​

OpenAI 有个 Tokenizer 工具：

OpenAI Tokenizer

进去输入文字，可以看到分词结果。

我试了一下：

  • Hello world → 2 Token
  • 你好世界 → 6 Token

同样的意思，中文 Token 数大概是英文的 2-3 倍。

分词算法​

Token 不是随便切的，有固定算法：

BPE GPT 系在用，把最常出现的字符对合并。

WordPiece BERT 在用，和 BPE 类似。

SentencePiece Google 出品，直接在原始文本上训练，不需要预分词。

中文一般用基于字的方案，或者混合中英文。

Token 和钱的关系​

API 按 Token 计费。第一次用 ChatGPT API 的时候，发现同样内容，英文和中文价格不一样。中文贵很多。

算一下：

  • 1000 字中文 ≈ 1500 Token
  • 1000 字英文 ≈ 1250 Token
费用 = (输入 Token + 输出 Token) × 单价

同样的对话，中文比英文贵 1-2 倍。

上下文窗口​

上下文窗口是什么？我一开始完全不懂。

后来才理解：就是大模型一次能处理的 Token 总数，有上限。

模型窗口大小
GPT-3.54K-16K Token
GPT-48K / 32K / 128K
Claude 3200K Token

超了会怎样？

我试过：粘贴一篇文章让模型总结，超过窗口就直接截断。模型会说"根据提供的内容..."但说不出具体细节。

还有一个问题：聊久了会"忘记"前面的内容。窗口被撑爆了，最早的对话被挤出去了。

踩坑记录​

坑1：中文占 Token 更多 同样的意思，中文比英文贵。写 Prompt 能用英文就用英文。

坑2：窗口不是无限大 超了就截断，重要信息可能丢失。

坑3：代码也费 Token 变量名、缩进、空行都算 Token。

怎么省 Token？​

  1. 精简 Prompt：别啰嗦
  2. 用英文：技术内容英文更省
  3. 分段处理：长内容分批
  4. 监控用量：API 有用量统计，看一下用了多少

明天学 Embedding，看看大模型怎么把文字变成数字。
