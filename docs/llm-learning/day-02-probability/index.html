Day 2：概率与下一个 Token 预测

学习目标​

理解大模型如何通过概率预测生成文本，以及温度参数如何影响输出。

理论学习​

核心机制：下一个 Token 预测​

  • 大模型本质上是「概率机器」
  • 输入一段文本，模型预测下一个最可能出现的 Token
  • 重复这个过程，生成连贯的文本

概率分布示例​

输入: "今天天气"
可能的下一个 Token 及概率:
- "很好" → 35%
- "不错" → 25%
- "糟糕" → 15%
- "晴朗" → 10%
- ...

温度参数（Temperature）​

Temperature效果适用场景
0.0-0.3确定性强，输出稳定代码生成、事实问答
0.4-0.7平衡，既有创意又可靠一般对话、写作辅助
0.8-1.2创意性强，多样性高头脑风暴、创意写作
1.5+随机性极高，可能失控实验性创作

其他关键参数​

  • Top-p (nucleus sampling): 只从概率累计前 p% 的 Token 中选择
  • Top-k: 只考虑概率最高的 k 个 Token
  • Max tokens: 限制生成长度

动手实践​

任务：体验温度参数的影响​

  1. 打开任意 AI 对话工具（Claude、ChatGPT、Kimi 等）
  2. 用相同的提示词，测试不同温度设置：
    • 提示词: "写一个关于未来城市的开头段落"
    • 分别用 temperature: 0.2, 0.7, 1.0
  3. 对比三个输出的差异

检查点问题​

  1. 为什么 temperature=0 时，同样的输入总是得到同样的输出？
  2. 温度很高时，模型可能会出现什么问题？
  3. 写代码时，你倾向于用高温度还是低温度？为什么？

今日产出​

  • 用同一提示词测试至少 3 个不同温度
  • 记录观察到的差异
  • 回答检查点问题
