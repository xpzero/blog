Day 2：概率与下一个 Token 预测

一句话理解​

大模型本质是概率机器，通过预测"下一个最可能出现的词"来生成文本。

术语释义​

什么是"下一个 Token 预测"？​

核心机制：

输入："今天天气"
预测：下一个最可能出现的词是什么？

可能选项：
- "很好" → 35% 概率
- "不错" → 25% 概率  
- "糟糕" → 15% 概率
- "晴朗" → 10% 概率
- ...

类比理解：

  • 就像手机的输入法联想
  • 你输入"今天天气"，输入法推荐"很好"
  • 模型做同样的事，但更复杂、更智能

概率分布​

什么是概率分布？

模型对每一个可能的下一个词，都给出了一个概率值，所有概率加起来等于 100%。

输入："我喜欢吃"

概率分布：
├── "苹果"     20%
├── "香蕉"     15%
├── "火锅"     12%
├── "寿司"     10%
├── "披萨"      8%
└── ...        35%（其他所有可能）

温度（Temperature）​

温度是什么？

控制模型"创造力"的参数，影响概率分布的"尖锐程度"。

温度值效果类比
0.0-0.3保守、确定性强严谨的教授
0.4-0.7平衡、可靠正常的同事
0.8-1.2有创意、多样艺术家
1.5+随机、可能失控喝醉的诗人

技术解释：

  • 低温：概率分布更"尖锐"，高概率词更容易被选中
  • 高温：概率分布更"平坦"，低概率词也有机会被选中

Top-p 和 Top-k​

Top-k： 只考虑概率最高的 k 个选项

Top-k=3：只从概率前 3 的选项中选择

Top-p（Nucleus Sampling）： 从概率累计达到 p% 的选项中选择

Top-p=0.9：从概率累计 90% 的选项中选择（可能 5 个词，也可能 50 个词）

原理解释​

模型如何计算概率？​

简化流程：

输入文本 → 神经网络计算 → 输出概率分布 → 采样生成下一个词

具体过程：

  1. 编码：将输入文本转为数字向量
  2. 注意力计算：理解上下文关系
  3. 全连接层：计算每个可能词的概率
  4. Softmax：将分数转为概率（总和为 100%）
  5. 采样：根据概率选择一个词

为什么同样的输入，输出可能不同？​

原因：随机采样！

温度=0.7 时的采样过程：

第一次：
- "很好" 35% → 被选中 ✓

第二次：
- "不错" 25% → 被选中 ✓（虽然概率低，但运气好）

特殊情况：

  • 温度=0 时：总是选概率最高的（确定性输出）
  • 温度>0 时：有随机性，输出可能不同

实际应用​

场景 1：代码生成（低温）​

需求： 写一段 Python 排序代码

设置：

Temperature: 0.2
Top-p: 0.95

原因：

  • 代码需要准确、可预测
  • 不需要"创意"，需要"正确"

示例输出：

def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        for j in range(0, n-i-1):
            if arr[j] > arr[j+1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]
    return arr

场景 2：创意写作（中高温）​

需求： 写一个科幻故事开头

设置：

Temperature: 0.8
Top-p: 0.95

原因：

  • 需要创意和多样性
  • 允许一些"意外"的表达

示例输出：

公元 2147 年，火星殖民地的第 47 个清晨，
艾琳醒来时发现窗外的红色沙尘暴中，
隐约浮现出一个不属于这个时代的身影...

场景 3：头脑风暴（高温）​

需求： 给新产品起名字

设置：

Temperature: 1.0
Top-p: 0.99

原因：

  • 需要大量创意点子
  • 不怕"离谱"，追求多样性

示例输出：

产品名称候选：
1. 星际漫游者
2. 量子跃迁
3. 时光胶囊
4. 梦境编织者
5. 平行宇宙

动手实践​

任务 1：体验温度差异​

使用相同的提示词，测试不同温度：

提示词：

写一句关于春天的描述

记录结果：

温度输出 1输出 2特点
0.2??
0.7??
1.0??

观察： 温度越高，输出差异越大吗？

任务 2：应用场景匹配​

为以下场景选择合适的温度：

场景推荐温度原因
数学计算?
写诗?
翻译?
头脑风暴?
事实问答?
参考答案
场景推荐温度原因
数学计算0.0-0.3需要准确
写诗0.7-0.9需要创意
翻译0.3-0.5准确为主
头脑风暴0.8-1.0追求多样性
事实问答0.0-0.3需要准确

任务 3：理解随机性​

实验：

  1. 设置温度=0，输入"你好"，记录输出
  2. 再次输入"你好"，记录输出
  3. 设置温度=0.7，重复 5 次

观察： 温度=0 时，输出是否完全相同？

检查点​

自测问题​

  1. 大模型如何生成文本？

    Details

    答案 通过预测下一个最可能出现的 Token，循环往复生成

  2. 温度参数的作用是什么？

    Details

    答案 控制输出的随机性和创造性，低温保守，高温随机

  3. 什么时候应该用低温（0.0-0.3）？

    Details

    答案 需要准确、确定性的场景，如代码生成、数学计算、事实问答

  4. Top-p 和 Top-k 的区别？

    Details

    答案 Top-k 固定选前 k 个，Top-p 选概率累计达 p% 的选项（数量不固定）

今日总结​

核心概念：

  • ✅ 模型通过预测下一个 Token 生成文本
  • ✅ 概率分布决定每个词的可能性
  • ✅ 温度控制输出的随机性

应用场景：

  • ✅ 代码生成 → 低温
  • ✅ 创意写作 → 中高温
  • ✅ 头脑风暴 → 高温
