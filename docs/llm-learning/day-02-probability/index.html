Day 2：概率与下一个 Token 预测

大模型生成文本的方式，跟输入法联想差不多——根据前面的内容，猜下一个最可能出现的词。

核心机制​

下一个 Token 预测​

输入："今天天气"
预测：下一个词是什么？

可能选项：
- "很好" → 35%
- "不错" → 25%
- "糟糕" → 15%
- "晴朗" → 10%
- ...

模型会给每个可能的词打分（概率），然后按概率采样。这就是大模型"说话"的基本原理。

概率分布​

模型对每一个可能的下一个词，都给出了一个概率值，所有概率加起来等于 100%。

输入："我喜欢吃"

概率分布：
├── "苹果"     20%
├── "香蕉"     15%
├── "火锅"     12%
├── "寿司"     10%
├── "披萨"      8%
└── ...        35%（其他所有可能）

温度（Temperature）​

控制"随机性"的参数，影响概率分布的"尖锐程度"。

温度值效果适用场景类比
0.0-0.3保守、确定性强代码、数学、事实问答严谨的教授
0.4-0.7平衡、可靠日常对话、翻译正常的同事
0.8-1.2有创意、多样写作、头脑风暴艺术家
1.5+随机、可能失控慎用喝醉的诗人

原理：

  • 低温：概率分布更"尖锐"，高概率词更容易被选中
  • 高温：概率分布更"平坦"，低概率词也有机会被选中

实际效果：

温度=0.2（低温）：

输入：写一句关于春天的描述
输出：春天来了，万物复苏。
（每次输出都差不多）

温度=1.0（高温）：

输入：写一句关于春天的描述
输出1：春风拂面，桃花盛开。
输出2：冰雪消融，溪流潺潺。
输出3：燕子归来，柳絮飞舞。
（每次输出差异很大）

Top-p 和 Top-k​

除了温度，还有两个控制采样的参数：

Top-k​

只考虑概率最高的 k 个选项：

Top-k=3：只从概率前 3 的选项中选择

Top-p（Nucleus Sampling）​

从概率累计达到 p% 的选项中选择：

Top-p=0.9：从概率累计 90% 的选项中选择
（可能 5 个词，也可能 50 个词，动态调整）

对比：

  • Top-k：固定数量，简单直接
  • Top-p：动态数量，更灵活

通常两个参数一起用，比如 top_k=50, top_p=0.95。

为什么同样的输入，输出可能不同？​

因为随机采样！

温度=0.7 时的采样过程：

第一次：

  • "很好" 35% → 被选中 ✓

第二次：

  • "不错" 25% → 被选中 ✓（虽然概率低，但运气好）

特殊情况：

  • 温度=0 时：总是选概率最高的（确定性输出）
  • 温度>0 时：有随机性，输出可能不同

场景选择指南​

代码生成（低温）​

Temperature: 0.2
Top-p: 0.95

原因： 代码需要准确、可预测，不需要"创意"，需要"正确"。

示例： 写 Python 排序函数，每次输出应该是一样的、能运行的代码。

创意写作（中高温）​

Temperature: 0.8
Top-p: 0.95

原因： 需要创意和多样性，允许一些"意外"的表达。

示例： 写科幻故事开头，希望每次都有新鲜感。

头脑风暴（高温）​

Temperature: 1.0
Top-p: 0.99

原因： 需要大量创意点子，不怕"离谱"，追求多样性。

示例： 给新产品起名字，希望有尽可能多的选项。

事实问答（低温）​

Temperature: 0.0-0.3

原因： 需要准确的事实，不能随机编造。

动手实验​

实验 1：温度对比​

使用相同的提示词，测试不同温度：

提示词：

写一句关于春天的描述

记录结果：

温度输出 1输出 2输出 3特点
0.2???几乎相同
0.7???有些差异
1.0???差异很大

观察： 温度越高，输出差异越大。

实验 2：应用场景匹配​

为以下场景选择合适的温度：

场景推荐温度原因
数学计算0.0-0.3需要准确
写诗0.7-0.9需要创意
翻译0.3-0.5准确为主
头脑风暴0.8-1.0追求多样性
事实问答0.0-0.3需要准确

实验 3：理解随机性​

步骤：

  1. 设置温度=0，输入"你好"，记录输出
  2. 再次输入"你好"，记录输出
  3. 设置温度=0.7，重复 5 次

观察： 温度=0 时，输出是否完全相同？

今日总结​

核心概念：

  • 模型通过预测下一个 Token 生成文本
  • 概率分布决定每个词的可能性
  • 温度控制输出的随机性和创造性

应用场景：

  • 代码生成 → 低温（0.0-0.3）
  • 创意写作 → 中高温（0.7-0.9）
  • 头脑风暴 → 高温（0.8-1.0）
  • 事实问答 → 低温（0.0-0.3）

关键参数：

  • Temperature：控制随机性
  • Top-k：固定选前 k 个
  • Top-p：动态选概率累计达 p% 的
