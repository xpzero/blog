大模型学习：从零拆开黑盒的入门地图

同一个问题问两次，答案不一样；对话拉长了，它开始忘记前面说过什么；明明一本正经，给出的资料却根本不存在。天天用 Cursor 和聊天助手，这些现象人人都撞见过，但要解释"为什么"，光会用是不够的——输入一段话、吐出一段话，中间是个黑盒。

这个系列是把黑盒拆开的学习记录：**一句话发出去，到一段文字回过来，中间每一站都发生了什么。**不要求任何机器学习基础，会一点编程即可（示例代码都很短，看注释就能懂）。

先看全貌​

一次最普通的模型调用，数据大致走这么一条线：

模型没有记忆、不会主动联网、也没有"想法"——它只做一件事：根据当前收到的全部文本，反复预测下一个词。后面每一篇拆一站。

阅读顺序​

一、输入侧：文字怎么变成模型能算的东西

  1. Token 与分词——模型不按"字"读文本。这篇用真实请求对照本地计数和服务端计数，还会看到一个意外结果：你发 1 个字符，服务端可能算你几千个 token。
  2. Embedding——"相似"是怎么变成一个可计算的数的。实测五句话的向量相似度，包括两个露馅的结果。

二、模型内部：一次前向传播里数据怎么流动

  1. Transformer 全景——从 token ID 进去到概率表出来，中间有几站。
  2. 注意力机制——模型怎么决定"该看哪几个词"。Query/Key/Value 各自干什么。
  3. 位置编码——为什么要额外告诉模型词的顺序。

三、输出侧：一个字一个字是怎么定下来的

  1. 概率与采样——temperature、top_p 到底改了什么。实测把 temperature 拧到两端，结果和教科书对不上。
  2. KV Cache 与自回归——为什么流式输出首字慢、后面快。
  3. 上下文窗口——长了为什么崩，中间的内容为什么容易被忽略。

四、模型的性格从哪来

  1. 训练与微调——预训练和对齐分别塑造了什么，以及什么条件下才值得微调。

这个系列不讲什么​

  • 不讲数学推导。 涉及公式的地方只说明它在做什么，并给出原始论文或教程链接，有兴趣可以自行深入。
  • 不讲 Prompt、RAG、Agent。 这些是"怎么用模型"的应用层话题，在 Agent 学习系列里——那边从第一次用代码调用大模型开始，一步步手写出一个命令行 Agent。两个系列共用同一套环境（uv + openai SDK）。
  • 不承诺结论跨模型成立。 带实测的文章会注明用的模型和方法；换服务商、换版本，数字会变，但观察方法不变。

环境说明​

带实测的篇目（01、02、06）用 Python 跑真实请求，环境和 Agent 系列一致：uv 管依赖、openai SDK、密钥放 .env。搭建步骤见 Agent 系列第一篇，这里不重复。纯讲解的篇目不需要任何环境。
