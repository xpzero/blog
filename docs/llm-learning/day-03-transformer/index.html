Day 3：Transformer

Tokenizer 把文字切成块，Embedding 把每块变成向量。接下来怎么让大模型理解这些向量？

靠 Transformer。

Transformer 是什么？​

Transformer 是大模型的"大脑"，处理输入向量，产出输出向量。

主流大模型（GPT、Claude、LLaMA）都是基于 Transformer。

先搞清两个概念​

Transformer 论文里有两个关键模块：Encoder 和 Decoder。

Encoder：

  • 负责理解输入
  • 看完整个输入，给出一个表示

Decoder：

  • 负责生成输出
  • 一个词一个词地往外蹦

三种常见架构：

  • BERT：只用 Encoder（理解任务强，比如分类、问答）
  • GPT：只用 Decoder（生成任务强，比如写文章、代码）
  • T5：两个都用（翻译、摘要等）

我们主要关注 GPT 这种 Decoder-only 架构，因为现在的大模型基本都是这种。

Attention 机制​

Transformer 的核心是 Self-Attention。

我一开始不懂这名字，后来理解：

Self：自己的意思

Attention：注意力

"自己注意自己"？这什么意思？

看例子：

句子："猫坐在垫子上，因为它累了"

问：这里"它"指谁？

  • 人类知道"它"指"猫"，因为"猫累了"
  • Self-Attention 让模型也能知道这个关系

怎么做到的？

每个词都会"看"其他词，计算自己和谁关系最密切。"它"的 Query 会和"猫"的 Key 匹配度高，所以"注意"到"猫"。

这就是 Self-Attention，"自己"和"自己"之间的关系。

Transformer 结构​

简化版：

输入向量 → [Self-Attention × N] → [FFN × N] → 输出向量

Self-Attention 让每个词知道和其他词的关系。

FFN（Feed-Forward Network）做进一步处理，提取更复杂的特征。

这两个模块会重复很多层（N=12, 24, 96...），层数越多，模型越"深"。

位置编码​

Self-Attention 只算关系，不考虑位置。

"猫追狗"和"狗追猫"，对 Attention 来说是一样的——它不知道谁在追谁。

所以要加 位置编码，告诉模型每个词在哪。

方法有几种：

  • Sinusoidal：用正弦余弦函数
  • Learned：让模型自己学

现在的模型常用 Learned，直接学一个位置向量加进去。

为什么 Transformer 强？​

相比之前的 RNN：

RNNTransformer
并行计算串行（要等前面算完）完全并行
长距离依赖容易丢信息直接"看"到任意位置
训练速度慢快

Transformer 解决了 RNN 的两个致命问题，所以成了主流。

踩坑记录​

坑1：Transformer 不是只有一个 "Transformer" 是一个大类。BERT、GPT、T5 都是基于 Transformer，但用法不一样。BERT 只能理解，不能生成。

坑2：层数不是越多越好 层数越多参数越多，能力越强，但训练和推理也越慢、越吃显存。不是越大越好，要看场景。

坑3：Attention 是 O(n²) 复杂度 序列越长，Attention 计算量增长是平方级的。长上下文会爆炸，所以才有各种优化（Flash Attention、MQA、GQA）。

总结​

  • Transformer 是大模型的核心架构
  • Encoder 理解，Decoder 生成
  • Self-Attention 让每个词"看"其他词
  • 位置编码解决词序问题

明天继续聊 Attention，看看它具体怎么工作的。
