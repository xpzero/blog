注意力机制：模型怎么决定"该看哪几个词"

"这家店的服务很差，但它的咖啡确实不错"——要判断"它"指什么，人会自然地回头找"这家店"。模型也要解决同一个问题：处理某个位置时，前文那么多 token，哪些相关、该参考多少？

上一篇说过，注意力（attention）是 Transformer 里 token 之间唯一交换信息的通道。这篇把这个通道拆开：Query、Key、Value 三个名词各自是什么，一次注意力计算到底算了什么。照旧不推公式，但会把数据流向走完整。

先给一句话版本​

注意力 ＝ 对前文所有位置打相关性分数，再按分数加权混合它们的信息。

两步：先决定"看谁、看多重"，再决定"拿走什么"。Query/Key/Value 就是为这两步服务的三个角色。

Query / Key / Value：一次检索的三方分工​

这套命名直接借自检索系统，拿图书馆对号入座：

  • Query（查询）：你写在检索单上的主题。代表"我在找什么"。
  • Key（键）：每本书书脊上的分类标签和索引卡。代表"我是什么，拿什么被检索"。
  • Value（值）：书的正文内容。检索命中后真正拿走的东西。

注意力里，每个 token 同时扮演三种角色。每个位置的向量会分别乘三个不同的矩阵（模型训练出来的参数），得到自己的 Q、K、V 三个向量：

token 向量 ──× Wq──> Query 向量   "我想找什么样的上下文"
          ──× Wk──> Key 向量     "我能提供什么样的信息"
          ──× Wv──> Value 向量   "命中我时，实际带走的内容"

为什么要拆成三份，而不是直接拿原向量互相比？因为"怎么被找到"和"找到后给什么"是两码事——"它"这个代词的 Key 应该长得像"可以被代词回指的实体"，而它的 Value 应该携带指代对象的语义。三个矩阵让模型对同一个 token 的三种角色分开建模。

一次完整的注意力计算​

以图中 Token 3 为例（对应图内高亮的 Query），从左到右三步：

  1. 产出三件套：四个 token 各自算出 Q、K、V。
  2. 打分（图中间）：Token 3 的 Query 和所有 token 的 Key 逐一做点积，得到 4 个原始分数；分数过一遍 softmax 压成总和为 1 的权重——图里四条长短不一的 Weight 条。哪个 Key 和这个 Query "对得上"，哪条就长。
  3. 加权混合（图右侧）：用这 4 个权重对 4 个 Value 加权求和，得到 Token 3 位置的输出向量。权重大的 token，它的 Value 在结果里占比就高。

每个位置都独立跑一遍这个流程（都用自己的 Query），所以 n 个 token 就有 n×n 对打分——这个平方关系记住，第 8 篇讲上下文窗口时它是主角。

两个图里没画、但必须知道的细节：

  • 只许往回看。 聊天模型是逐词生成的，预测时看不到未来，所以位置 i 的 Query 只和位置 ≤ i 的 Key 打分（术语叫 causal mask，因果掩码）。
  • 不止一套 Q/K/V。 实际每层会并行跑几十组独立的注意力（multi-head，多头），每组关注不同类型的关系——有的头盯语法搭配，有的头盯指代。各头结果拼起来再送下一站。

权重是算出来的，不是查出来的​

这是注意力和传统检索最本质的区别，也是它"聪明"的来源：图书馆的索引卡是预先编好的，而注意力的权重每次前向传播都根据当前上下文现算。同一个词在不同句子里，Q/K/V 全都不同：

"苹果发布了新手机"   → "苹果"的 Key 更容易被"发布""手机"的 Query 命中
"苹果三块钱一斤"     → 同一个"苹果"，Key 偏向被"三块钱""一斤"命中

所谓"模型理解了上下文"，机制层面就是这么回事：每个词的表示都被它周围的词重新塑造过。几十层注意力叠下来，一个 token 的向量里已经混入了整段文本的信息。

容易误会的三个地方​

  • 没有"聚焦"这回事。 注意力不是把目光锁定在某个词上，而是所有前文都参与、只是权重不同。哪怕权重 0.001 的 token 也在结果里留了痕迹。
  • 权重不等于"重要性"的解释。 可视化注意力权重看起来很直观，但研究界对"注意力权重能否解释模型行为"长期有争议（文末有链接），拿它做归因要谨慎。
  • 这一步没有任何"知识"。 注意力只负责搬运和混合信息，"巴黎是法国首都"这类事实主要存在前馈网络的参数里。注意力决定看哪，前馈决定想起什么。

公式在哪​

整个机制在论文里就一行：Attention(Q,K,V) = softmax(QKᵀ/√d)·V，其中 √d 是防止点积过大的缩放项。想看推导和维度细节，直接读 Attention Is All You Need 第 3.2 节，或图文并茂的 The Illustrated Transformer。
