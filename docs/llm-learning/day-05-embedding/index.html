Day 5：嵌入与向量数据库

刚开始接触 Embedding 的时候，我也懵——把文字变成数字？这玩意儿能干啥？后来做 RAG 的时候才明白，没有它，检索根本玩不转。

一句话理解​

Embedding 就是把文字、图片这种人类能懂的东西，转成机器能算的向量。意思相近的内容，向量也挨得近。

举个例子​

"苹果" 的向量 ≈ [0.2, -0.5, 0.8, ...]  
"水果" 的向量 ≈ [0.3, -0.4, 0.7, ...]  
"苹果手机" 的向量 ≈ [0.9, 0.1, -0.2, ...]

算一下余弦相似度：

  • "苹果" 和 "水果" → 0.85（挺近）
  • "苹果" 和 "苹果手机" → 0.45（还行）
  • "水果" 和 "苹果手机" → 0.12（基本没关系）

机器就靠这个判断语义关系。

维度选择​

维度说明
384 维all-MiniLM，轻量，本地跑够用
768 维BERT 系列，平衡选择
1536 维OpenAI text-embedding-3-small
3072 维OpenAI text-embedding-3-large

维度越高表达能力越强，但存储和计算成本也越高。我一般 384 或 1536 够用。

常用模型​

模型维度特点
text-embedding-3-small1536OpenAI，便宜
text-embedding-3-large3072OpenAI，性能好
all-MiniLM-L6-v2384开源，本地跑
bge-large-zh1024中文优化
m3e-base768中文开源

选型：英文用 OpenAI，中文用 bge/m3e，资源紧张用 384 维。

怎么算相似度​

余弦相似度（最常用）​

import numpy as np

def cosine_similarity(a, b):
    return np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b))

vec1 = embed("机器学习")  # 假设已转向量
vec2 = embed("深度学习")
vec3 = embed("苹果派")

cosine_similarity(vec1, vec2)  # ≈ 0.85
cosine_similarity(vec1, vec3)  # ≈ 0.20

欧氏距离​

def euclidean_distance(a, b):
    return np.linalg.norm(a - b)

euclidean_distance(vec1, vec2)  # 距离小 = 相似
euclidean_distance(vec1, vec3)  # 距离大 = 不相似

余弦相似度看方向，欧氏距离看绝对位置。文本检索一般用余弦。

向量数据库​

为什么需要​

100 万条文本找最相似的 10 条，暴力搜索要几秒。向量数据库用 ANN（近似最近邻）算法，毫秒级。

ANN 算法​

HNSW（最常用）：

  • 多层图结构，像高速公路
  • 顶层快速跳跃，底层精确定位
  • 速度快，召回率>95%
  • 内存占用大

IVF：

  • 先聚类再搜索
  • 内存效率高
  • 建索引快

主流产品​

数据库特点
Pinecone全托管，开箱即用
Weaviate开源，本地部署
Milvus高性能，生产环境
Chroma轻量，开发测试
pgvectorPG 扩展

RAG 里的 Embedding​

准备阶段：

原始文档 → 切分（500-1000 Token）→ Embedding → 存向量库

查询阶段：

用户提问 → Embedding → 向量检索（Top K）→ 塞给 LLM → 生成回答

关键参数：

  • 分块大小：500-1000 Token
  • 重叠：10-20%
  • Top K：3-10
  • 相似度阈值：0.5-0.7

动手试试​

用 OpenAI 做 Embedding​

from openai import OpenAI
client = OpenAI()

def get_embedding(text):
    response = client.embeddings.create(
        input=text,
        model="text-embedding-3-small"
    )
    return response.data[0].embedding

words = ["苹果", "水果", "苹果手机", "华为"]
embeddings = {w: get_embedding(w) for w in words}

本地跑（免费）​

pip install sentence-transformers
from sentence_transformers import SentenceTransformer

model = SentenceTransformer('all-MiniLM-L6-v2')
embeddings = model.encode(["机器学习", "深度学习", "苹果派"])

语义搜索​

pip install chromadb
import chromadb
from sentence_transformers import SentenceTransformer

client = chromadb.Client()
collection = client.create_collection("docs")
model = SentenceTransformer('all-MiniLM-L6-v2')

# 添加文档
docs = ["机器学习是AI的分支", "深度学习用神经网络"]
collection.add(
    embeddings=model.encode(docs).tolist(),
    documents=docs,
    ids=["d0", "d1"]
)

# 搜索
results = collection.query(
    query_embeddings=model.encode(["AI技术"]).tolist(),
    n_results=2
)

今天学了啥​

  • Embedding：文本 → 向量，语义相近的向量也近
  • 余弦相似度：最常用的相似度算法
  • 向量数据库：ANN 实现快速检索
  • RAG：文档向量化 → 检索 → 生成

选型建议：快速验证用 Chroma，生产用 Milvus，中文用 bge/m3e。
