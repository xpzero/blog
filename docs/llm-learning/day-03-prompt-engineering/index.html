Day 3：提示工程

提示工程说白了就是——把话说清楚，让 AI 准确理解你要什么。

不是魔法咒语，不是编程语言，就是清晰的沟通技巧。

为什么需要提示工程？​

模型不知道：

  • 你是谁
  • 你的背景知识
  • 你想要什么格式
  • 你的使用场景

你需要告诉它！

四个基本原则​

1. 明确具体（5W1H）​

❌ 差的提示：

写点关于猫的东西

问题： 太模糊，模型不知道你要什么

✅ 好的提示：

写一篇 200 字的科普短文，介绍家猫的睡眠习惯，
面向 10 岁儿童，语气轻松有趣

优点：

  • 明确体裁（科普短文）
  • 明确长度（200 字）
  • 明确主题（睡眠习惯）
  • 明确受众（10 岁儿童）
  • 明确语气（轻松有趣）

2. 提供上下文​

❌ 差的提示：

优化这段代码

问题： 没有上下文，模型不知道优化目标

✅ 好的提示：

这是一段 Python 数据处理代码，运行在处理 10GB CSV 文件时很慢。
请优化性能，优先考虑内存效率，保持代码可读性。

代码：
[粘贴代码]

优点：

  • 说明场景（处理大文件）
  • 说明问题（速度慢）
  • 说明优先级（内存效率）
  • 说明约束（保持可读性）

3. 指定格式​

❌ 差的提示：

列出远程工作的好处

问题： 输出格式不确定

✅ 好的提示：

请用表格形式列出远程工作的 5 个好处和 3 个挑战，
表格包含三列：方面、描述、应对建议

优点： 输出格式明确，易于使用

4. 角色设定​

技巧： 让模型扮演特定角色

示例：

你是一位资深 Python 工程师，有 10 年数据分析经验。
请审查以下代码，关注性能问题和 Pythonic 写法：

[代码]

效果：

  • 模型会站在专家角度回答
  • 回答更专业、更深入
  • 自动过滤基础内容

其他角色示例：

  • "你是一位经验丰富的产品经理..."
  • "你是一位小学老师，擅长用简单语言解释复杂概念..."
  • "你是一位资深前端工程师，专注于 React 性能优化..."

进阶技巧​

技巧 1：Few-shot（少样本示例）​

定义： 给模型几个示例，让它按同样格式输出

示例：

将以下中文翻译成英文：

示例 1：
中文：你好
英文：Hello

示例 2：
中文：谢谢
英文：Thank you

现在翻译：
中文：很高兴认识你
英文：

适用场景：

  • 特定格式输出
  • 风格模仿
  • 分类任务
  • 数据提取

技巧 2：Chain-of-Thought（思维链）​

定义： 让模型逐步思考，展示推理过程

示例：

问题：一个农场有鸡和兔，头共 35 个，脚共 94 只。
鸡和兔各有多少只？

请一步一步思考并解答。

效果：

  • 提高复杂问题的准确率
  • 可以检查模型的推理过程
  • 便于发现错误

适用场景：

  • 数学问题
  • 逻辑推理
  • 多步骤任务

技巧 3：约束条件​

定义： 明确告诉模型边界和限制

示例：

请用一句话总结以下文章，
要求：
- 不超过 20 个字
- 不要技术术语
- 包含核心观点

其他约束示例：

  • "只列出前 3 个最重要的点"
  • "用初中生能听懂的语言解释"
  • "不要提及具体的公司名称"

技巧 4：输出模板​

定义： 提供具体的输出结构

示例：

请分析以下产品，按以下格式输出：

## 产品名称
[名称]

## 目标用户
[用户群体]

## 核心功能
- [功能 1]
- [功能 2]

## 优缺点
优点：
- [优点 1]

缺点：
- [缺点 1]

## 改进建议
[建议]

优点：

  • 输出结构化，易于解析
  • 确保覆盖所有要点
  • 方便后续处理

实际应用案例​

案例 1：代码解释​

任务： 让 AI 解释一段不懂的代码

❌ 差提示：

解释这段代码

✅ 好提示：

请解释以下 Python 代码的功能和工作原理。
假设我是初学者，对装饰器概念不熟悉。

代码：
```python
@timer
def fetch_data(url):
    return requests.get(url).json()

请说明：

  1. 这段代码做什么？
  2. @timer 是什么意思？
  3. 实际应用场景

### 案例 2：学习规划

**任务：** 制定一周学习计划

**❌ 差提示：**

帮我制定学习计划


**✅ 好提示：**

我是一名上班族，想学习 Python 数据分析。 每天能投入 1 小时，周末可以 2 小时。 目前基础：会基础 Python，不会 pandas。

请制定一周学习计划，要求：

  • 具体到天
  • 包含学习资源和练习任务
  • 目标：能处理 CSV 数据并生成图表

### 案例 3：内容创作

**任务：** 写产品推广文案

**❌ 差提示：**

写个产品介绍


**✅ 好提示：**

为一款智能手环写推广文案。

产品特点：

  • 续航 14 天
  • 心率监测
  • 睡眠分析
  • 价格 199 元

目标受众：25-35 岁上班族，关注健康但没时间运动

要求：

  • 3 个不同风格的版本（专业/亲切/幽默）
  • 每个版本 100 字左右
  • 突出性价比

### 案例 4：数据分析

**任务：** 分析销售数据

**✅ 好提示：**

你是一位数据分析师，擅长销售数据分析。

数据： [粘贴数据]

请分析：

  1. 总体销售趋势
  2. 最畅销的 3 个产品
  3. 销售额下降的可能原因
  4. 下个月的销售预测

输出格式：

  • 用表格展示关键数据
  • 每个分析点用 bullet point
  • 最后给出 3 条 actionable 建议

## 常见错误

### 错误 1：太模糊

❌ "写点东西" ✅ "写一篇关于远程工作优势的博客文章，800 字，面向职场新人"


### 错误 2：没有上下文

❌ "优化这段代码" ✅ "这段 Python 代码处理 10GB 数据时内存溢出，请优化内存使用"


### 错误 3：没有指定格式

❌ "总结一下" ✅ "用 3 个 bullet point 总结，每个不超过 20 字"


### 错误 4：一次性提太多要求

❌ "写一个完整的电商网站，包括前端后端数据库" ✅ 分步骤：先写需求文档 → 再写数据库设计 → 再写 API 接口...


## 今日总结

**核心原则：**
- 明确具体（5W1H）
- 提供上下文
- 指定格式
- 角色设定

**进阶技巧：**
- Few-shot（给示例）
- Chain-of-Thought（逐步思考）
- 约束条件
- 输出模板

**记住：** 提示工程不是一次性完美的，需要反复迭代优化。
