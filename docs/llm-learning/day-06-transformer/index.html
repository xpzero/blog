Day 6：Transformer 架构

2017 年 Google 那篇《Attention Is All You Need》一出来，整个 NLP 圈都疯了。之前做翻译要用 RNN 一层层串，慢得要死，Transformer 直接并行搞，速度起飞。

看论文的时候被 Query Key Value、多头注意力这些名词砸得晕头转向。后来自己动手实现了一遍才懂，核心就一句话：让每个词都能直接看到其他所有词。

整体结构​

Transformer 就两大块：Encoder 和 Decoder。

输入 → [Encoder × N] → 上下文表示 → [Decoder × N] → 输出

Encoder 把输入文本变成向量，每个词一个向量，带上下文信息。Decoder 拿着这些向量，一个词一个词生成输出。

BERT 只用 Encoder，GPT 只用 Decoder，T5 两个都用。

Self-Attention：核心创新​

RNN 的问题是，看 distant word 要一层层传，信息会丢。Self-Attention 让任意两个词直接"对视"，距离不再是问题。

怎么算的​

每个词变出三个向量：

  • Query (Q)：我要查什么
  • Key (K)：我有什么
  • Value (V)：我的实际内容

然后算注意力分数：

Attention(Q, K, V) = softmax(Q × K^T / √d_k) × V

分步看：

  1. Q 和 K 点乘，算出每对词的"相关度"
  2. 除以 √d_k 防止数值太大
  3. softmax 变成概率分布
  4. 乘 V 得到加权后的输出

直观理解​

句子："猫坐在垫子上，因为它累了"

问："它"指谁？

  • "它"的 Q 和 "猫"的 K 匹配度高
  • 注意力权重高，模型就知道"它" = "猫"

这就是 Self-Attention 的威力——长距离依赖不再是问题。

Multi-Head Attention​

一套 Q/K/V 不够，来 8 套，每套关注不同的"关系"。

Head 1: 语法关系（主谓宾）
Head 2: 指代关系（他/她/它指谁）
Head 3: 语义相似（同义词）

最后把各头的结果拼接起来，再过一层线性变换。

MultiHead(Q, K, V) = Concat(head_1, ..., head_h) × W^O
where head_i = Attention(Q × W_i^Q, K × W_i^K, V × W_i^V)

位置编码​

Self-Attention 有个问题：它不知道词的位置。"猫追狗"和"狗追猫"对它来说一样，都是三个词的集合。

解决方案：Positional Encoding，给每个位置一个独特的"指纹"。

Sinusoidal 位置编码（原版）​

PE(pos, 2i)   = sin(pos / 10000^(2i/d_model))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))

用正弦/余弦函数生成，好处是每个位置编码唯一，可以处理训练时没见过的更长序列。

Learned Positional Encoding（BERT/GPT 用）​

直接让模型学，每个位置一个向量，简单直接。

position_embeddings = nn.Embedding(512, 768)

其他组件​

Feed-Forward Network​

每个位置独立过同一个全连接网络：

FFN(x) = max(0, x × W1 + b1) × W2 + b2

两层线性变换 + ReLU，把 Attention 的输出再变换一下。

Layer Normalization​

稳定训练用的，对每个样本的所有特征做归一化。

LayerNorm(x) = γ × (x - μ) / √(σ² + ε) + β

Residual Connection​

output = LayerNorm(x + Sublayer(x))

把输入直接加到子层输出上，防止梯度消失，训练更深网络。

完整流程​

Encoder 一层​

输入 x
  ↓
Multi-Head Self-Attention
  ↓
Add & Norm（残差 + LayerNorm）
  ↓
Feed-Forward Network
  ↓
Add & Norm
  ↓
输出

堆 6 层（或 12、24 层，看模型大小）。

Decoder 一层​

比 Encoder 多一个 Cross-Attention：

输入 x
  ↓
Masked Multi-Head Self-Attention（不能看未来词）
  ↓
Add & Norm
  ↓
Cross-Attention（Q 来自 Decoder，K/V 来自 Encoder）
  ↓
Add & Norm
  ↓
Feed-Forward
  ↓
Add & Norm

为什么 Transformer 这么强​

特性RNNTransformer
并行计算串行完全并行
长距离依赖逐步传递直接连接
训练速度慢快

代价是 O(n²) 的复杂度，序列长的话内存爆炸。这就是后来各种高效 Attention（Linear Attention、Sparse Attention）要解决的问题。

动手看看注意力权重​

from transformers import BertTokenizer, BertModel
import matplotlib.pyplot as plt
import seaborn as sns

tokenizer = BertTokenizer.from_pretrained('bert-base-chinese')
model = BertModel.from_pretrained('bert-base-chinese', output_attentions=True)

text = "猫坐在垫子上"
inputs = tokenizer(text, return_tensors='pt')
outputs = model(**inputs)

# 获取最后一层的注意力权重
attentions = outputs.attentions[-1]

# 可视化第 0 个 head
plt.figure(figsize=(8, 6))
sns.heatmap(attentions[0, 0].detach().numpy(), 
            xticklabels=tokenizer.convert_ids_to_tokens(inputs['input_ids'][0]),
            yticklabels=tokenizer.convert_ids_to_tokens(inputs['input_ids'][0]),
            cmap='YlOrRd')
plt.title('Attention Weights')
plt.show()

可以看到哪些词在"关注"哪些词。

今天学了啥​

  • Self-Attention：任意两词直接交互，解决长距离依赖
  • Multi-Head：多套注意力，捕获不同关系
  • 位置编码：给模型位置信息
  • 残差 + LayerNorm：稳定训练

Transformer 是现代 LLM 的基石。BERT、GPT、T5、LLaMA 都是它的变体。
