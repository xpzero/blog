Day 6：Transformer 架构

学习大模型，绕不开 Transformer。现在主流的模型（GPT、Claude、LLaMA）都是基于它。

整体结构​

Transformer 有两大块：Encoder 和 Decoder。

输入 → [Encoder × N] → 上下文表示 → [Decoder × N] → 输出
  • Encoder：理解输入，把文本变成带上下文信息的向量
  • Decoder：基于这些向量，逐个生成输出

实际应用：

  • BERT：只用 Encoder（理解任务）
  • GPT：只用 Decoder（生成任务）
  • T5：两个都用（翻译、摘要）

Self-Attention：核心机制​

传统方法（如 RNN）看 distant word 要一层层传，信息会丢。Self-Attention 让任意两个词直接"对视"，距离不再是问题。

怎么工作的​

每个词生成三个向量：

  • Query (Q)：我要查什么
  • Key (K)：我有什么
  • Value (V)：我的实际内容

然后算注意力分数：

Attention(Q, K, V) = softmax(Q × K^T / √d_k) × V

简单说：

  1. Q 和 K 点乘，算相关度
  2. 除以 √d_k 防数值过大
  3. softmax 变概率分布
  4. 乘 V 得加权输出

直观例子​

句子："猫坐在垫子上，因为它累了"

问："它"指谁？

  • "它"的 Q 和 "猫"的 K 匹配度高
  • 注意力权重高，模型知道"它" = "猫"

这就是 Self-Attention 的威力——长距离依赖不再是问题。

Multi-Head Attention​

一套 Q/K/V 不够，来多套（通常 8 套），每套关注不同关系。

Head 1: 语法关系（主谓宾）
Head 2: 指代关系（他/她/它指谁）
Head 3: 语义相似（同义词）

最后把各头结果拼接，再过线性变换。

位置编码​

Self-Attention 不知道词的位置。"猫追狗"和"狗追猫"对它一样，都是三个词。

需要显式注入位置信息。

两种方式​

Sinusoidal（正弦/余弦）：

PE(pos, 2i)   = sin(pos / 10000^(2i/d_model))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))

Learned（学习的）：

position_embeddings = nn.Embedding(512, 768)

现在大部分模型用 Learned，简单直接。

其他组件​

Feed-Forward Network​

每个位置独立过全连接网络：

FFN(x) = max(0, x × W1 + b1) × W2 + b2

两层线性变换 + ReLU。

Layer Normalization​

稳定训练，对每个样本特征做归一化。

Residual Connection​

output = LayerNorm(x + Sublayer(x))

输入直接加到子层输出，防梯度消失。

为什么 Transformer 强​

特性传统方法Transformer
并行计算串行完全并行
长距离依赖逐步传递直接连接
训练速度慢快

代价是 O(n²) 复杂度，序列长内存爆炸。后来各种高效 Attention 就是解决这个问题。
